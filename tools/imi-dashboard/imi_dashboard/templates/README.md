# {display_name} — IMI Dashboard

A static website showing methane emissions estimated by an
[Integrated Methane Inversion](https://imi.seas.harvard.edu/) run. Everything
it needs is in this folder, except the base map, which the browser downloads
from a tile server (by default OpenStreetMap); offline, the maps show on a
plain background.

```
.
├── index.html               the entry page
├── README.md                this file
├── imi-dashboard-app.json   list of the pages' files, for imi-dashboard
├── assets/                  JavaScript, CSS, fonts, logo (licences in THIRD-PARTY-LICENSES.md)
└── data/                    the inversion outputs
```

Do not edit these files: `imi-dashboard convert` rewrites them on update. It
leaves anything else you add (e.g. `.git/`, `CNAME`) alone.

## Viewing it

It must be served over HTTP; opening `index.html` from disk (`file://`) does
not work.

**Locally**, with Python 3, in this folder:

```bash
python -m http.server 8000
```

then open <http://localhost:8000>; `Ctrl+C` stops the server.

**Online**: upload the folder as it is, with `index.html` at its top, to any
static host: Netlify, Vercel, Cloudflare Pages, GitHub Pages, Amazon S3, Azure
Blob Storage or a plain web server. No configuration is needed, and sub-paths
such as `https://<user>.github.io/<repository>/` work.
